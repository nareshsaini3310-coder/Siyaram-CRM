# Stage A Builder File: Navigation And Workflow

Use with `followup_app_design_prompt.md`.

## Scope

Implement and verify the five-part mobile workflow:

- Aaj: daily count, `Shuru karo`, and next actions.
- Projects: project cards and project detail/edit.
- Leads: lead list, Client Profile, and Excel import.
- Visit: calls, meetings, visits, overdue work, and follow-ups.
- Refer: existing tags/labels workspace until a dedicated referral model exists.

## Required Overlays

- Post-call card rises from the bottom and saves call outcome, notes, next action, follow-up, and optional recording.
- Settings opens from the top and contains Light / Dark / Phone plus `Effects: Minimal / Standard / Full`.

## Stage A Acceptance

- Navigation works on phone and desktop.
- Client Profile and Project Detail preserve their back routes.
- Excel import remains reachable from Leads.
- Follow-up work remains reachable from Aaj and Visit.
- Unresolved Sec. 2.2 questions must be reported, not guessed.
